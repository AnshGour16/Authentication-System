Role-Based Access Control (RBAC)

Cryptographic OTP Reset

Brute-Force & Lockout Defense

Adaptive attempt tracking invalidates OTP after 5 incorrect guesses, and locks user accounts for 15 minutes after 5 consecutive failed login attempts.

Security Architecture Flow

How an incoming authentication request is validated across security boundaries

1

Perimeter Defense

Helmet HTTP headers, CORS policies, and multi-tier rate limiting evaluate incoming request rate and headers.

2

Input Sanitization

Strict type validation, length capping (128 char max for passwords to prevent ReDoS), and NoSQL operator rejection.

3

Cryptographic Engine

Bcrypt salted hashing (10 rounds) verifies credentials. Lockout tracker monitors attempt limits in real-time.

4

Token Issuance

Stateless JWT signed with role claims. Database records audit log and returns authorized session.
