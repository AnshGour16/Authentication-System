Engineered for Enterprise Defense

Comprehensive architectural layers safeguarding credentials against modern attack vectors

Role-Based Access Control (RBAC)

Strict segregation between Standard Users and Administrators with dedicated role middleware, administrative user directory, and status toggles.

Cryptographic OTP Reset

High-speed direct SSL email dispatch (Gmail SMTP port 465) with single-use replay attack wipe defense and 60-second cooldown timers.

Brute-Force & Lockout Defense

Adaptive attempt tracking invalidates OTP after 5 incorrect guesses, and locks user accounts for 15 minutes after 5 consecutive failed login attempts.

Stateless JWT Verification

Signed JSON Web Tokens carrying role and identity claims for stateless REST API consumption with 24-hour expiration and instant validation.

Multi-Tier HTTP Hardening

Tiered rate limiting via express-rate-limit across general, auth, and OTP endpoints, Helmet Content Security Policies, and strict NoSQL injection guards.

Observability & Audit Trail

Real-time client IP logging, browser/device detection, active session tracking, and a global administrative audit trail for compliance.

Security Architecture Pipeline

How authentication requests traverse security boundaries

01. Perimeter Defense

Helmet HTTP security headers, CORS policies, and rate-limiting evaluate incoming request rates.

02. Input Sanitization

Strict type validation, length capping (128 chars max for passwords), and NoSQL operator rejection.

03. Cryptographic Engine

Bcrypt salted hashing (10 rounds) verifies credentials. Lockout tracker monitors attempt limits in real-time.

04. Token & Audit

Stateless JWT signed with role claims. Database records audit log and returns authorized session.
